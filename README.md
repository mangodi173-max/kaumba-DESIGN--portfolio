# Kaumba Gordon Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Pages

- `index.html` - Home page and portfolio overview
- `contact.html` - Contact form and contact details
- `HTML/About.html` - About page
- `HTML/prices.html` - Services and pricing table

## Run Locally

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

1. Upload the project files to a GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Select the main branch and the root folder.
4. Save and open the generated Pages URL.
